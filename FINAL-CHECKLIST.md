# Portfolio final checklist

This project includes the four screenshots supplied by the portfolio owner, profile image, and a downloadable resume.

## Run
```bash
npm install
npm run build
npm run dev
```

## Verify before submission
- Test the resume button; it points to `/resume.pdf`.
- Test all four project cards and links, at `/projects/<slug>`.
- Inspect in Chrome Incognito (disable extensions if hydration warnings persist).
- Test 375px, 768px, 1280px widths.
- Run `npm audit` to examine dependency reports. Do not run `npm audit fix --force` blindly.
- Push to your GitHub repository and deploy to Vercel, then check the live website.

## Important
- Screenshots were supplied by the owner and represent projects, not live browser captures here.
- The portfolio has not been automatically deployed to a live URL.
